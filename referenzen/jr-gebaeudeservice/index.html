Die Ausgangslage

Komplett unsichtbar bei Google. 6 Bewertungen — die Konkurrenz hatte 300+.

  • 01

    2 widersprüchliche Telefonnummern auf der Website — Kunden erreichten den falschen Anschluss.

  • 02

    Leeres Impressum — § 5 TMG-Abmahnrisiko, aktiv ungesichert.

  • 03

    2 Google-Business-Profile — Duplikate schwächen die SEO-Signale gegenseitig.

  • 04

    3 parallele Domains ohne SEO-Strategie — kein Keyword-Fokus, kein Canonical.

  • 05

    0 Schema-Markup, 0 Citations in Branchenverzeichnissen.

  • 06

    6 Google-Bewertungen — Hauptmitbewerber lagen bei 319+.

Die Lösung

Kompletter Static-HTML-Neubau, Local-SEO, GBP-Bereinigung.

Phase 1

Vollständiger Audit

On-Page-SEO, Local-SEO, Design, GBP-Status — alle Schwachstellen dokumentiert, priorisiert.

Phase 2

Neubau Static HTML

Neue Website auf Static HTML + Tailwind — mobil, Core Web Vitals grün, Schema.org LocalBusiness, korrektes Impressum.

Phase 3

Local SEO + eigene Standort-Seiten

Duplikat-Profil zusammengeführt, primäre + 9 Sekundär-Kategorien, NAP-Konsistenz, 15+ Branchenverzeichnisse. Dazu eigene Local-SEO-Seiten für jede Leistung und jeden Ort im Einzugsgebiet — gezielt auf die Suchbegriffe seiner Kunden ausgerichtet.

Phase 4

Launch + QA

Deployment auf Vercel, GA4 + GTM eingerichtet, Web3Forms-Kontaktformular, Google Search Console verifiziert.

Sichtbar in der ganzen Region — nicht nur in Falkensee.

Über 40 eigene Standort-Seiten — eine für jede Leistung und jeden Ort im Einzugsgebiet, von Falkensee über das Havelland bis ins Berliner Umland. So wird JR Gebäudeservice heute auch in den Nachbarorten gefunden — Anfragen kommen aus Orten, in denen vorher nie geworben wurde.
